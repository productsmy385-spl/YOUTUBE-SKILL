# Sir's YouTube Agentic Studio — Build Kit

This kit is the implementation brief for turning the supplied DropX Admin starter into an AI-assisted Telugu video production and YouTube operations platform.

## Included
- `MASTER_BUILD_PROMPT.md` — paste into Antigravity or Claude Code after opening the DropX Admin repository.
- `skills/youtube-creative-director/SKILL.md` — reusable agent skill for converting a dialogue/idea into a complete video package.
- `docs/PRODUCT_ARCHITECTURE.md` — product modules, agent workflow, data model and integrations.
- `docs/DESIGN_SYSTEM.md` — visual system based on the supplied palette and DropX Admin conventions.
- `docs/IMPLEMENTATION_ROADMAP.md` — staged build and acceptance gates.
- `.env.example` — names of expected secrets; values intentionally blank.

## Important
This is a build specification and agent skill pack, not a completed application. The coding agent must inspect the actual repository and implement in small, verified phases. Do not paste API keys into prompts or commit secrets.
